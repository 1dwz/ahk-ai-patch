# Read by BOTH tools/build.ps1 (to warn when a build's output drifts) and the CI
# verify job (to fail when it does).  Keeping the list in one place is the point:
# a second hard-coded copy in the workflow already caused a red run, when the
# HTTP/JSON guide was added to dist/ and the workflow list did not know about it.
#
# Rules:
#   - one entry per line, file name only (artifacts are flat)
#   - <arch> is replaced with 64 for the x64 artifact, 32 for Win32
#   - '#' starts a comment
#
# Everything listed must be produced by tools/build.ps1 -OutDir.  Nothing that
# is loadable at runtime may appear here: no DLL, no CA bundle, no sidecar
# config.  libcurl is linked into the executable, so cmd tests passing with only
# the exe and a script present is the whole promise this file guards.
